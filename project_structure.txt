Cross-platform (Metal/CUDA/D3D12) voxel path-tracing engine. macOS Metal is primary; Windows CUDA/D3D12 supported.

## Memory Model (4-Level Sparse)

1. **Indirection**: Toroidal 3D MTLTexture (R32Uint) → SectorBuffer index
2. **Sector Buffer**: `SectorInfo` with 64-bit brickMask + baseBrickIndex
3. **Occupancy**: 4x4x4 block status (64-bit integers in BrickPool)
4. **Voxel Data**: Material IDs (uchar), 512 bytes per brick

## 8-Pass Rendering Pipeline (MetalRenderer::Draw)

| Pass | Kernel | Output |
|------|--------|--------|
| 0 | distApproximationKernel | Half-res depth |
| 1 | GBufferAndDirectLight | Albedo, Normal, Motion, Direct Light |
| 2 | IndirectBounce | GI (noisy) |
| 3 | TemporalAccumulation | Reprojected, accumulated GI |
| 4 | BilateralDenoise | A-Trous filtered GI |
| 5 | VolumetricFog | God-rays, scattering |
| 6 | ComputeExposure | Luminance avg |
| 7 | Composite | HDR + tone-map |

Post: MetalFX temporal upscaling + TAA

## Key Algorithms (intersections.h)

- Character AABB intersections: O(1) vs bounding box + 6 body parts
- `GetStepPos()`: Level 1→2→3 hierarchy checks
- LOD: `GetIsotropicLOD()` skips empty regions
- Bitwise: `popcnt64()` + `BitTestHalf64` for cell boundaries

## Build Commands

```bash
# CMake
mkdir build && cd build && cmake ..

# Windows (CUDA + D3D12)
cmake -G "Visual Studio 17 2022" -A x64 ..
cmake --build . --config Release

# macOS (Metal)
cmake -G Xcode ..
cmake --build . --config Release
```

## Critical Rules

1. **16-byte alignment** for all `simd_float4x4` / GPU data structs
2. Keep `.shader` files synchronized between Metal and CUDA code paths
3. Minimize thread divergence in Metal kernels
4. Path tracing is expensive; add features as single extra traces when possible
