4. Code Duplication Patterns Between Metal and CUDA
A. BrickPool Implementation (HIGH DUPLICATION)
Files: BrickPool.mm vs CudaBrickPool.cu
Aspect	Metal
Lines	107
Allocation Logic	IDENTICAL
Free Logic	IDENTICAL
Next-Fit Algorithm	IDENTICAL
Duplication Rate: ~95% - Only differs in:
- Memory allocation: [dev newBufferWithLength:] vs cudaMalloc()
- Logging: NSLog() vs fprintf()
- Buffer storage mode: MTLStorageModePrivate vs raw pointers
B. Buffer Implementation (MODERATE DUPLICATION)
Files: MetalBuffer.mm vs CudaBuffer.cu
Method	Metal
Allocate()	newBufferWithLength:
Free()	m_buffer = nil
Readback()	memcpy()
GetSize()	[buffer length]
Duplication Rate: ~80% - Same interface, different APIs
C. Renderer Pipeline (STRUCTURAL DUPLICATION)
Files: MetalRenderer.mm (558 lines) vs CudaRenderer.cu (626 lines)
Both implement the exact same 8-pass pipeline:
1. Distance Approximation (half-res)
2. GBuffer + Direct Light (full-res)
3. Indirect Bounce (GI)
4. Temporal Accumulation
5. Bilateral Denoise (3 iterations)
6. Volumetric Fog (half-res)
7. Compute Exposure
8. Composite
Duplication Pattern:
- Identical render target creation logic
- Identical camera/framedata preparation
- Identical kernel dispatch order
- Different API calls for kernel launch
D. Shader Code (NOW UNIFIED)
Previously duplicated in *.metal and *.cu files.
Current approach uses shader_macros.h to unify:
// Platform abstraction examples:
#define KERNEL(name) kernel void name        // Metal
#define KERNEL(name) __global__ void name    // CUDA
#define TEX_WRITE_2D(tex, val, coord) tex.write(val, coord)  // Metal
#define TEX_WRITE_2D(tex, val, coord) surf2Dwrite(val, ...)  // CUDA

5. Build Configuration Analysis
CMakeLists.txt Structure
Windows Build (CUDA + D3D12):
  - Finds CUDA Toolkit
  - Preprocesses .shader files → .cu via C preprocessor
  - Links: d3d12, dxgi, dxguid
  - Optional: Streamline SDK (DLSS)
macOS Build (Metal):
  - Compiles .metal files → .air
  - Links .air → default.metallib
  - Links: Cocoa, Metal, MetalKit, MetalFX, QuartzCore
  - Creates stub CudaRenderer for compilation
