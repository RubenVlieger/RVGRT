C. Renderer Pipeline (STRUCTURAL DUPLICATION)
Files: MetalRenderer.mm (558 lines) vs CudaRenderer.cu (626 lines)
Both implement the exact same 8-pass pipeline:
1. Distance Approximation (half-res)
2. GBuffer + Direct Light (full-res)
3. Indirect Bounce (GI)
4. Temporal Accumulation
5. Bilateral Denoise (3 iterations)
6. Volumetric Fog (half-res)
7. Compute Exposure
8. Composite
Duplication Pattern:
- Identical render target creation logic
- Identical camera/framedata preparation
- Identical kernel dispatch order
- Different API calls for kernel launch

## BUG FIXES APPLIED (Post-Refactoring)

### Issue: Black/Pink/Dark Artifacts on Screen
**Symptoms:** Random uninitialized memory showing as colored artifacts that move with camera

**Root Causes Found:**
1. MetalFX Temporal Scaler not being created (missing from refactored initialization)
2. Render targets created with uninitialized GPU memory (MTLStorageModePrivate)

**Fixes Applied:**

#### Fix 1: Create MetalFX Temporal Scaler
File: `src/renderer/Metal/MetalRenderer.mm`
- Added `CreateTemporalScaler()` method
- Called after `Initialize()` in constructor
- Creates MTLFXTemporalScaler with proper input/output dimensions

#### Fix 2: Clear History Buffers
File: `src/renderer/Metal/MetalRenderer.mm`
- Added `ClearHistoryBuffers()` method
- Clears all ping-pong buffers (depth, accum, finalHistory, volumetric) to black on startup
- Uses render pass with MTLLoadActionClear to zero-initialize textures
- Called after render targets created, before world generation

#### Files Modified:
- `src/renderer/Metal/MetalRenderer.mm` - Added CreateTemporalScaler() and ClearHistoryBuffers()
- `include/renderer/MetalRenderer.hpp` - Added method declarations

#### Key Lesson:
When refactoring, ensure all initialization steps from original code are preserved:
- Render target creation
- Buffer clearing/initialization  
- Temporal scaler setup
- World generation order matters (clear before generate)
