# RVGRT Cross-Platform Migration Plan

## Project Overview
Port the Windows/CUDA path to match the macOS/Metal architecture using MaterialMap + BrickPool 
and the 8-pass deferred rendering pipeline.

## Architecture

| Platform | GPU API  | Renderer      | Data Structures          |
|----------|----------|---------------|--------------------------|
| macOS    | Metal    | MetalRenderer | MaterialMap, BrickPool   |
| Windows  | CUDA     | CudaRenderer  | CudaMaterialMap, CudaBrickPool |

Both platforms share:
- Unified `.shader` source files (preprocessed for Metal/CUDA)
- `intersections.h` (cross-platform ray tracing)
- `shader_macros.h` (platform abstraction)

## File Structure (Current State)

### Cross-Platform (Shared)
```
include/
  renderer/ShaderTypes.h      # Platform-typed math (simd_float3 / float3)
  renderer/intersections.h    # Ray tracing (Metal/CUDA/C++)
  shader_macros.h             # Platform abstraction macros

src/renderer/kernels/shaders/
  *.shader                    # Unified shader sources (10 files)
```

### macOS-Specific
```
src/renderer/
  MetalRenderer.mm            # 8-pass Metal pipeline
  MaterialMap.mm              # SVO streaming (Metal buffers)
  BrickPool.mm                # Brick allocator
  *.metal                     # Metal kernels (compiled by xcrun)
```

### Windows-Specific
```
src/renderer/
  CudaRenderer.cu             # 8-pass CUDA pipeline (mirrors MetalRenderer)
  CudaMaterialMap.cu          # SVO streaming (CUDA malloc)
  CudaBrickPool.cu            # Brick allocator
  D3D12Device.cpp             # D3D12 + optional Streamline

src/platform/
  win32_main.cpp              # Windows entry point
```

---

## Key Design Decisions

1. **Unified Shaders**: Single `.shader` source -> preprocessed to `.metal` / `.cu`
2. **Flat Buffers for CUDA**: 3D textures emulated with `index = x + y*W + z*W*H`
3. **Streamline Optional**: DLSS requires SDK download, disabled by default
4. **Identical Algorithms**: Same ray traversal logic on all platforms (see intersections.h)
5. **8-Pass Pipeline Order**: dist_approx -> GBuffer/Direct -> Indirect -> Temporal -> Denoise(3x) -> Volumetric -> Exposure -> Composite

## Dependencies

**Required:**
- CMake 3.10+
- CUDA Toolkit 11.0+ (Windows)
- Xcode 15+ / macOS 14.0+ (macOS)
- Visual Studio 2022 (Windows)
- C Preprocessor: cpp or clang-cpp (Windows, for shader preprocessing)

**Optional:**
- NVIDIA Streamline SDK v2.9.0 (for DLSS support)
  - Download: https://github.com/NVIDIAGameWorks/Streamline/releases
  - Extract to: `vendor/streamline-sdk-v2.9.0/`
  - Enable with: `cmake .. -DUSE_STREAMLINE=ON`
